JiraSync for Sheets

Import Jira Cloud issues into Google Sheets with JQL. Pick any field, including custom fields, and keep it refreshed.

Status: coming soon. It is waiting for Google Workspace Marketplace review, so it isn't installable yet. Email likeaustinpowers@gmail.com to get early access.

Screenshot shows sample data, not a real Jira site.

What it does

  • JQL import: any Jira Cloud query goes straight into a tab. It uses Jira's current search API (/rest/api/3/search/jql).
  • Field picker: search and pick columns from all your Jira fields, including custom fields like Story Points, Sprint or Team. Each saved import keeps its own columns.
  • Saved imports and Refresh all: re-run every import in the sheet with one click from the Extensions menu.
  • Change-history and worklog tabs (Pro): one row per field change (who, when, from, to) and one row per worklog. Good for cycle-time and time-tracking reports.
  • Scheduled refresh (Pro): every 1, 6, 12 or 24 hours. If a refresh fails, you get at most one email per import per day.
  • Formula: =JIRA_JQL("project = ABC ORDER BY updated DESC", "summary,status,assignee")
  • Private by design: it only works on the open spreadsheet, and your API token stays in your Google account. Runneth Labs runs no servers. See the privacy policy.

Setup

1. Create a Jira API token

  1. Sign in to Atlassian and open id.atlassian.com → Security → API tokens.
  2. Click Create API token (a regular token, not one with scopes), name it "JiraSync for Sheets", and pick an expiry date. Atlassian tokens last at most 1 year.
  3. Click Copy. You won't be able to see the token again after you close the dialog.

2. Connect

  1. In Google Sheets, open Extensions → JiraSync for Sheets → Connect & import…
  2. Enter your Jira site (for example yourteam.atlassian.net), your Atlassian account email and the token, then click Connect.

3. Import

  1. Type a JQL query, for example project = ABC AND statusCategory != Done ORDER BY updated DESC.
  2. Click Load and tick the columns you want. Use search to find custom fields.
  3. Choose a tab name and click Import. JiraSync won't overwrite a tab that already holds other data.

4. Pro (optional)

  1. Buy Pro on Gumroad (link coming at launch) and paste the license key into the sidebar's Pro section.
  2. Turn on Change history tab or Worklog tab for an import, and set Auto-refresh.

Troubleshooting

  • "Jira rejected the credentials (HTTP 401)": the token is wrong or expired. Create a new token and connect again.
  • "Jira rejected the query": test the JQL in Jira's issue search first.
  • Only 500 rows: that's the Free plan limit, so upgrade to Pro for more.
  • Removing access: click Disconnect & delete token in the sidebar, and revoke the token at id.atlassian.com.
